Newton-Raphson Method as Python Script

The Newton-Raphson Method is a very fast and effective method, but it requires the first and second derivatives of the function analyzed. For the function: $$ y = x^2 + 5 $$ The first and second derivatives are: $$ \frac{dy}{dx} = 2x $$ $$ \frac{d^2y}{dx^2} = 2 $$ For the Newton-Raphson Method, we still start with an initial guess of x0. The equation for Newton-Raphson calculates the next guessed x-value with the following equation: $$ x_{n+1} = x_{n} + \frac{f'(x_{n})}{f''(x_{n})} $$ The python script on the Assignment 1 Part 1 Code page implements the Newton-Raphson Method, and includes a check which compares the difference in consecutive x-values to see if they are within an error tolerance of 1e-7.

The following plots show the shortest distances between the quadratic equation above and several points, described in the table below, with the value of the shortest calculated distance. The initial guesses were kept constant across the test cases as x_initial = 5.

The plots on the right show the final shortest distance between the point and the function.


Notice that in the last 2 plots, the 'shortest distance' calculated is 7.972, which is incorrect. For the point (-5.3, 12.9), the x-value on the function that would yield the shortest distance should occur on the left side of the x-y plane, where x values are negative. The Newton-Raphson approximation method failed to get the correct 'shortest distance' value because it was given an initial guess of x_initial = 5, which made the method fall into a relative minima in the objective function.

When we feed an alternate initial guess of x_initial = -5, the Newton-Raphson method finds the correct absolute minima of the objective function, yielding a 'shortest distance' value of 2.45180. This occurs at x_final = -2.88423, which was found after 5 iterations of the Newton-Raphson approximation method. The intermediate plot and final plot can be seen below.

Newton-Raphson Method on Logarithmic Function

The following table and plots shows the shortest distance objective function applied to an logarithmic function: $$ y = log_{3}(x) + 10 $$ The first derivative is: $$ \frac{dy}{dx} = \frac{1}{x \cdot ln(3)}$$ The second derivative is: $$ \frac{d^2y}{dx^2} = \frac{1}{x^2 \cdot ln(3)} $$
For logarithmic equations, the domain of acceptable x inputs is 0 to infinity. Thus, the points chosen ensure that x > 0.

This is because although the objective function is indeed capable of evaluating x values that are less than 0, the Newton-Raphson algorithm would require a step from its initial guess (a positive number) and evaluate the functions at a negative number, which is a special case that would need to be handled differently.

For demonstrating profiency of the standard Newton-Raphson algorithm, all points that are fed to the algorithm require the x0 value to be greater than 0.

For example, instead of plugging in the usual (0,0) coordinate to get the distance of the point from the function, I chose to plug in (2,0). Out of the 4 quadrants tested, only the positive-x side and positive-y side of the x-y plane are tested (1 quadrant) with the set of coordinates of [8.2, 5.7].
